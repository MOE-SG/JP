ℹ️ About Moe's Schematic

Moe's Schematic v1.0  ·  Schematic & Panel Documentation Workspace

A self-contained, browser-based schematic capture tool. Every drawing lives on an A3 landscape sheet with a red ASME-style border, inch-accurate zone references, and an editable engineering title block — with no install, account, or server required.

Feature Overview
FileNew / Open / Save projects as portable .json files
OutputExport DXF (vector) and JPG (raster), or print an exact, borderless A3 sheet
Parts / BOMAuto-generated Bill of Materials — grouped by type & value, exportable as CSV or a printable A4 sheet
InsertFree-form text annotations and imported raster symbols/footprints
DrawLine, polyline, rectangle, circle, and terminal pins, with snap-to-grid
LibraryElectrical Components, Flow Chart Nodes, and Rack Systems Layout symbol sets
InspectorPer-part reference designator, value/rating, stroke color, label visibility, and pin editing
Title BlockEditable doc ID, company, revision, sheet, date, drawn-by, sheet size, and tolerance notes
Quick Controls
• Wires/Nets: select directly, or drag a box and press Backspace to clear.
• Move Pins: click a part, then drag any red terminal pin dot.
• Resize/Reshape: select a rectangle, circle, ellipse or polyline, then drag its blue handles.
• Marquee Box: drag empty canvas space to sweep-select multiple items.
• Group Drag: Ctrl+G groups a selection so dragging any member moves the whole group.
• Copy/Paste: Ctrl+C / Ctrl+V — pasted items are grouped so you can drag them all at once.
• Undo/Redo: Ctrl+Z / Ctrl+Shift+Z.
• Select All: Ctrl+A.
• Spacebar: rotate the highlighted selection 90°.
Installable as an app — use the 📲 Install button in the header (or your browser's install/Add to Home Screen option) to run it in its own window, with offline support after the first visit. Works on phones and tablets too — tap ☰ for the toolbar, ◂▸ for the library/inspector, and pinch with two fingers to zoom. Built for MOE's ENTERPRISE; all project data stays local in your browser — nothing is uploaded to a server.
